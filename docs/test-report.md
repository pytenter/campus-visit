## 本轮发现并修复的问题

1. UI 每次刷新重置 setLayout，导致重放刚开始就被取消：改为相同布局幂等更新。
2. A-Frame 的 remove() 在元素已经移除后再次调用会抛异常，导致 v2 刷新无法完成初始化：移除重复删除，改为只清理当前实际子元素。
3. UI 与实际路径侧廊转弯点不一致：地图、重走和人物统一读取 LAYOUTS。
4. 自动路线未取消会在用户导航后继续移动：导航使路线令牌失效并恢复面板。
5. 头显错误和信息热点只出现在网页层：增加世界面板及头显内 Canvas 提示。
6. 手柄默认模型会请求 CDN：禁用外部模型，保留本地射线。
7. 房间尺度旋转和地点导航未补偿追踪偏移：绕头部脚点旋转、按目标脚点平移。
8. 遮挡墙可被 WASD 穿过：移动增加墙体边界排除。
